THE ASHEN ROAD — PWA prototype 0.1

Files:
- index.html: app UI and logic
- manifest.json: install metadata
- sw.js: offline cache worker

Important:
For PWA installation and offline service-worker functionality, host these files on HTTPS (or run on localhost).
You can use static hosting (e.g. GitHub Pages) or a local development server.
The prototype currently saves game data in browser local storage on that device.

Combat is a provisional implementation based on the summarized playtest rules; it needs reconciliation and testing before relying on it as the definitive rules engine.
